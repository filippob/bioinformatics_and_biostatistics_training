Physalia workshop on Deep Learning for Life Sciences
=======================

- slides
- worked out [notebooks with exercises](notebooks/) (Python)

### Programme

#### Day 1
- Introduction to (deep) Neural Networks (DNN)
- Introduction to the operational system: Jupiter notebooks, Python modules, Keras/Tensorflow
- Supervised/unsupervised learning, different models for different problems: regression, classification, segmentation, counting

#### Day 2
- DNN for classification problems: logistic regression, softmax regression
- Notebooks on dense neural networks for classification
- Exercise on DNN for classification

#### Day 3
- Convolutional Neural Networks (CNN)
- Cross-validation and model selection
- Practical cross-validation and convolutions

#### Day 4
- Data augmentation
- “Bayesian” learning (pill)
- Underfitting, overfitting, recipe for a good project

#### Day 5
- Transfer learning
- Embeddings, self-attention, transformers: a primer
- A gentle introduction to LLMs
